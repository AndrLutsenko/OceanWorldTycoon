ЯК ОТРИМАТИ APK БЕЗ ANDROID STUDIO

1. Створи на github.com новий ПУБЛІЧНИЙ репозиторій (New repository).
2. Розпакуй цей ZIP на комп’ютері.
3. Завантаж у репозиторій УСІ файли й папки з OceanWorld_GitHub_APK, включно з прихованою папкою .github (важливо!).
   Якщо браузер не завантажує приховану .github, створи файл .github/workflows/build-apk.yml вручну через Add file > Create new file і скопіюй текст з архіву.
4. Відкрий Actions > Build Android APK > Run workflow (або дочекайся автоматичного запуску після завантаження).
5. Дочекайся зеленого статусу збірки, відкрий її, внизу сторінки Artifacts завантаж OceanWorldTycoon-APK.
6. Розпакуй завантажений ZIP: всередині app-debug.apk. Перенеси його на телефон і встанови.

Це проєкт для складання APK, а не готовий APK. Успішність збірки на GitHub ще не перевірено.
