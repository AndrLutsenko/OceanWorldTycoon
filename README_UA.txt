OCEAN WORLD TYCOON — ANDROID STUDIO PROJECT

Це повний вихідний Android-проєкт, а не готовий APK.

1. Встановіть Android Studio на Windows: https://developer.android.com/studio
2. Розпакуйте архів.
3. Android Studio -> Open -> виберіть папку OceanWorldAndroid.
4. Дочекайтеся Gradle Sync. Якщо потрібно, встановіть Android SDK 35.
5. Меню Build -> Build Bundle(s) / APK(s) -> Build APK(s).
6. APK буде у app/build/outputs/apk/debug/app-debug.apk.
7. Перенесіть APK на Android і встановіть.

Для першої збірки потрібен інтернет. Android Studio може попросити встановити JDK 17.
Гра працює офлайн, зберігає прогрес на пристрої, не потребує дозволів.
